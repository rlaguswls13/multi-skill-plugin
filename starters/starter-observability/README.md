Aggregates:
- `skill-trace-id-propagator`
- `skill-audit-logger`
- `skill-slow-query-interceptor`
- `skill-exception-analyzer`
- `skill-health-checker`
- `skill-structured-log-formatter`
- `skill-api-performance-profiler`
- `skill-memory-leak-detector`
